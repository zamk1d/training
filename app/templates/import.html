Импорт данных из JSON

Любой блок (exercises, meals, body) может быть пустым или отсутствовать — это нормально, если данные не сохранились. Упражнения поддерживают как новый формат reps_list (разные повторы по подходам), так и старый sets+reps.

Пример формата 
{
  "days": [
    {
      "date": "2025-01-15",
      "is_workout_day": true,
      "workout_notes": "Тяжело, но сделал",
      "exercises": [
        {"exercise_name": "Классические отжимания", "reps_list": [12, 10, 8]},
        {"exercise_name": "Алмазные отжимания", "reps_list": [8, 8, 6]}
      ],
      "meals": [
        {"date": "2025-01-15", "description": "Омлет из 3 яиц", "protein_g": 20},
        {"date": "2025-01-15", "description": "Курица с гречкой", "protein_g": 40}
      ],
      "body": {"date": "2025-01-15", "weight_kg": 67.2, "height_cm": 176}
    },
    {
      "date": "2025-01-16",
      "is_workout_day": false,
      "meals": [
        {"date": "2025-01-16", "description": "Творог 200г", "protein_g": 36}
      ]
    }
  ]
}
